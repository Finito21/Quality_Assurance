# Confluence

**Confluence** (Atlassian) is a tool for creating and managing **team documentation**, i.e. a company wiki. You can compare it to a shared Word document with change history, comments and a page structure. It integrates with [Jira](../test_management/jira.md).

## Structure

- **Space**: an area for a team or a project,
- **Page**: a page (with child pages forming a tree),
- **Templates**: ready-made templates (meeting notes, requirements, retrospective),
- **Macros**: dynamic elements, e.g. a list of Jira issues on a page.

## Use in a tester's work

- **test strategy and test plan**, description of test environments,
- **checklists** and notes from exploratory sessions,
- **requirements and user stories**, i.e. the basis for static testing,
- test reports and release notes,
- a knowledge base: access details for test environments, configuration instructions.

!!! tip
    The **Jira Issues** macro lets you embed an up-to-date list of bugs from a given sprint or version on a page, e.g. in a test report.
