# Automatyzacja testów API

**Automatyzacja testów API** - proces wykonywania testów API przy użyciu narzędzi i skryptów bez potrzeby ręcznej ingerencji. Testy mogą być uruchamiane automatycznie, np. w pipeline CI/CD, w celu ciągłej weryfikacji poprawności działania API oraz szybszego wykrywania błędów.
