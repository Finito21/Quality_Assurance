# **Quality Assurance Notes**

This site serves as a structured knowledge base in the field of Quality Assurance.

You will find here materials related to:

- QA and testing fundamentals  
- manual testing  
- basics of test automation  
- API testing  
- tools used in QA  

---

# **🎯 Purpose**

The purpose of this project is to:

- organize knowledge in the field of Quality Assurance  
- develop practical testing skills  
- build a practical, real-world approach to QA  

---

# **🧠 How the materials are created**

The materials on this site are based on:

- personal learning and hands-on practice  
- working with QA tools  
- publicly available sources and documentation  

A significant portion of the content is based on the ISTQB syllabus, which provides the theoretical foundation for many QA topics.

Links to the sources used are available in the **[Resources](resources.md)** section.

AI tools are also used during the content creation process, mainly for:

- structuring content  
- improving clarity and organization  
- refining explanations  

**All content is reviewed and validated before publication.**
