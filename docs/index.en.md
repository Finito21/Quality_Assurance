## Learning path

If you are starting from scratch, go through the material in this order:

1. **[QA fundamentals](fundamentals/qa_fundamentals.md)**: what testing is, principles, test levels and types.
2. **[Test techniques](fundamentals/test_techniques.md)** and **[documentation](fundamentals/test_documentation.md)**: how to design test cases and report defects.
3. **[Test management](fundamentals/test_management.md)**: planning, risk, the defect lifecycle.
4. **[HTML](technologies/frontend/html.md)**, **[DevTools](tools/devtools.md)** and **[Jira](tools/test_management/jira.md)**: everyday work with a web application and issues.
5. **[HTTP](technologies/api_testing/http.md)**, **[Postman](tools/api_testing_tools/postman.md)** and **[SQL](technologies/backend/sql.md)**: API testing and checking data in the database.
6. **[Git](tools/git/git_basics.md)**, **[test automation strategy](fundamentals/test_automation_strategy.md)** and **[Playwright](tools/automation/playwright.md)**: your first automated tests.

Finally, test yourself with the **[interview questions](fundamentals/interview_questions.md)**, and look up unknown terms in the **[glossary](fundamentals/glossary.md)**.

## About

QA Notes are notes from learning software testing: a testing course, preparation for the **ISTQB CTFL v4.0** exam, an internship and hands-on work with QA tools. The theory is based on the ISTQB syllabus, and the practical part on tool documentation and personal experience. The materials used are listed in **[Resources](resources.md)**.

AI tools help with organising and editing the texts, and every page is reviewed before publication. The content is continuously developed, and some topics are deliberately simplified.
